📖 About The Project

ARNA RETREAT is a modern, responsive, and user-friendly resort booking website developed to provide visitors with a convenient platform to explore resort accommodations, discover facilities, enjoy activities, and make room reservations.

The main objective of this project is to create a digital resort experience where users can explore different room categories, view resort services, manage their bookings, and share their experiences through customer reviews.

The website combines an attractive user interface with a Python Flask backend and SQLite database to support essential website operations.

---

🎯 Project Objectives

- Develop a modern and attractive resort website.
- Provide a smooth and user-friendly browsing experience.
- Allow users to register and log in securely.
- Display resort rooms and accommodation details.
- Enable users to make room reservations.
- Store and manage booking information.
- Provide users with access to their booking history.
- Showcase resort facilities, activities, and customer reviews.
- Connect frontend pages with backend functionality.

⚙️ How To Run The Project Locally

1. Clone the repository:

git clone https://github.com/hemajagadeesh468-dot/ARNA-RESORT-WEBSITE.git

2. Open the project folder in Visual Studio Code.

3. Set up Python and install the dependencies required by the Flask application.

4. Run the Flask backend application:

python app.py

5. Open the frontend in your browser using the appropriate local development setup.
